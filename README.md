# FloLabs Humanoid Projects

This repository contains the files and context for the projects from the Humanoid team.

## Repository Architecture

This repository is divided by each project the team is working on. Each project branch and main project directory is individual.

### Branches
The main branch contains the release version of each project. If the project you are looking for is not in the main branch, that means it does not have a stable version released yet, but we are working on it!

Each repository has a develop branch (develop-project_name) which has the current development status of the project. Every work should be done based on the project's develop branch.

### Directories

Each project corresponding work is on its own folder (/project_name). Any type of file corresponding to a project should be inside its folder. Each folder can have any type of file that seems fit to run or document the project.

It is suggested to document every work done and final decisions on this repository to mantain project full context as valuable information for coding artificial intelligent agents.

### Basic Information

Every project should have a READ.ME file explaining its purpose and architecture.

## Team Workflow

The work done on every project should follow the same guidelines to mantain a consistency. Those guidelines are: 

1. For every new feature or fix, a new branch should be created with the name formate: project_name-feat/feature_title or project_name-fix/fix_title
2. The directory's and file's name should be in snake case format
